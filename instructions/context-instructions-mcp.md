# Tools

## Code Search (jbcontext)

`code_search` is the main way to find code in this project, both by what it does and by the names you know. Make it your first code search in every task and use it for every code lookup after that: definitions, callers and usages, implementations, configuration or registrations. Use grep only when you need every literal occurrence of a string, e.g. before a rename.

Start with `code_search`, using the behavior and the names from the issue.
