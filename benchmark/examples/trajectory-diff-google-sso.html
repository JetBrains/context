## Summary

Yes, the `jetbrains-ai-platform` repo has an existing OAuth2/OIDC-style SSO infrastructure in the `auth/` module. **Google is already wired in as a login option**, but it is implemented as a *pass-through* to the JetBrains Account (JBA) OAuth provider — not as an independent, standalone Google OAuth/OIDC identity provider. Everything funnels through JetBrains Account.

---

## 1. Existing SSO / OAuth / OIDC infrastructure (file paths)

Core auth wiring lives in `auth/auth-service/src/main/kotlin/ai/grazie/auth/`:

- **`auth/Auth.kt`** — Central authentication bootstrap. `Auth.setup(application)` installs the Ktor `authentication {}` block, defines the local JWT auth (`jwt("jwt")`), the `grazie-auth-token`/`grazie-auth-redirect` cookies, logout route, and calls `setup()` on every individual provider (GoogleAuth, JetBrainsAuth, JBAJwtAuth, YouTrackAuth, IdeServicesAuth, DataloreAuth, LicenseServerAuth, TeamCityAuth, DarkMatterAuth). This is the hub where a new provider would be registered.
- **`auth/JetBrainsAuth.kt`** — The real OAuth2 Authorization-Code implementation. Uses Ktor's `oauth("jetbrains")` with `OAuthServerSettings.OAuth2ServerSettings` (authorizeUrl/accessTokenUrl/clientId/clientSecret, `defaultScopes = listOf("openid")`, a `CookieNonceManager`). On callback it fetches the JBA profile, registers the user, mints a local JWT, sets the cookie.
- **`auth/JBAJwtAuth.kt`** — Validates inbound JBA-issued JWTs via `jwt("jetbrains-jwt")` using a JWKS verifier; powers `/auth/jetbrains-jwt/*` endpoints (user-info, register, provide-access/license).
- **`api/OpenIdConfigurationAPIs.kt`** — Serves `/.well-known/openid-configuration` (just exposes `jwks_uri`).
- **`jwks/JBAJwksProvider.kt`, `jwks/KtorJwkProvider.kt`** — JWKS providers for JWT signature verification.
- **`jwt/GrazieLocalJWT.kt`, `jwt/cloud/GrazieCloudUserJWT.kt`** — Local JWT minting/verification.
- **`config/konfy/OAuthConfig.kt`** — Konfy config object holding all OAuth provider settings (see below).
- Config keys resolved from `oauth.*` properties (e.g. `secrets.properties` — not readable, credential-protected). Env conf files: `auth/auth-service/src/main/resources/application-{default,local,local-dev,perf,preprod,stgn,prod}.conf`.
- Route/path definitions: `auth/auth-model/src/commonMain/kotlin/ai/grazie/auth/model/api/AuthAPI.kt`.
- SSO enum: `auth/auth-model/src/commonMain/kotlin/ai/grazie/auth/model/SSO.kt`.
