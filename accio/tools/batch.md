- For repeated local queries in one project, use `{{JBCONTEXT}} batch --project /path/to/checkout` and send one JSON object per stdin line, for example `{"args":["symbol","Service","--source-lines"]}`. Replies stream before EOF, one ordered `{"stdout":"...","stderr":"...","code":0}` envelope per nonblank line. Only enabled local query commands and diff may run; semantic/context search, nested batches, and setup/maintenance commands are rejected with code 2 while later requests continue. Send `{"refresh":true}` before querying edits, or `{"refresh":"current"}` for the watcher's current set. `{"cancel":true}` cancels the preceding request; cancelled queries return code 130 and the cancel returns code 0. A cancel after a rejected request cancels nothing. Each line can set `--ref` or `--no-build`; `--project` must resolve to the batch's project. Close stdin to finish. A transport/process failure exits the wrapper nonzero; inspect every reply's code even when the process succeeds.
